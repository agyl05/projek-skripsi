# projek-skripsi
"klasifikasi hama dan penyakit tanaman daun cabai menggunakan convNeXt V2 berbasis Masked Autoencoders"
Deskripsi projek:
projek ini merupakan implementasi deep learning untuk klasifikasi citra daun cabai berddasarkan kondisi daun menggunakan arsitektur ConvNeXt V2 yang dikembangkan dengan pendekatan Masked Autoencoders (MAE). projek ini dibuat sebagai bagian dari penelitian skripsi untuk mengklasifikasikan citra daun cabai ke dalam beberapa kategori berdasarkan karakteristik visual yang terdapat pada daun.
